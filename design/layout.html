Zones

  1. 1
    Status

    TV name, power state and the app in front. Power sends KEY_POWER when on, Wake-on-LAN when in standby. The ⋯ menu holds Settings, Re-pair and Quit.

  2. 2
    Apps

    Names come from the TV, icons from each app's website. Drag to rearrange; the first ten show when collapsed. A dot marks running apps. Right-click to move or hide.

  3. 3
    Remote

    D-pad with OK in the middle. Back and Home on the left, Play/Pause and Info on the right, where the thumb sits on the real remote.

  4. 4
    Volume / CH

    Slider reads the TV's real volume over UPnP (0–100) and sets it directly. Channel stepper beside it.

  5. 5
    Type / Source

    Text you type goes into the TV's on-screen keyboard. Source menu lists TV and HDMI inputs.

Material

On macOS 26 the controls use Liquid Glass (glassEffect, interactive). This Mac runs macOS 15.6, so it falls back to the system popover material with the same shapes. One code path, checked with #available.
